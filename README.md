# gen-AI

A collection of generative AI experiments covering text generation, image synthesis, and prompt engineering techniques.

## Overview

This repository contains notebooks, scripts, and utilities for exploring modern generative AI models including large language models and diffusion-based image generators.

## Project Structure

```
gen-AI/
├── notebooks/       # Jupyter notebooks for experimentation
├── src/             # Reusable utilities and wrappers
├── prompts/         # Curated prompt templates
└── docs/            # Notes and references
```

## Getting Started

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Requirements

- Python 3.10+
- PyTorch 2.x
- transformers >= 4.35
- diffusers >= 0.25
